# Лабораторная работа № 3 — Доска публикаций

## Запуск
1. Распакуйте архив в отдельную папку.
2. Откройте index.html в браузере. Все четыре файла должны лежать рядом.
3. Для запросов к JSONPlaceholder требуется интернет.
Альтернатива: откройте папку через Live Server в VS Code.

## Состав
- index.html — интерфейс, форма, области сообщений и публикаций.
- style.css — адаптивное оформление.
- app.js — DOM, GET/POST, валидация, состояния загрузки и ошибки.
- README.md — запуск и проверка.

## Проверка: действия и ожидаемые результаты
Фактические запросы в браузере при подготовке архива не выполнялись.
Ниже приведён план ручной проверки; после запуска отметьте фактические результаты.

| Проверка | Ожидаемый результат | Фактический результат |
| --- | --- | --- |
| Нажать «Загрузить публикации» | 5 записей с заголовками и текстом, сообщение об успехе | Не проверено |
| Отправить пустую форму | Понятная ошибка, запрос не отправляется | Не проверено |
| Ввести только пробелы в одно или оба поля | Ошибка, запрос не отправляется | Не проверено |
| Ввести корректные заголовок и текст, отправить | POST с title, body, userId: 1; обычно HTTP 201; заголовок, текст и ID из ответа | Не проверено |
| В app.js временно изменить GET_URL на https://jsonplaceholder.typicode.com/postz | Сообщение об HTTP 404, кнопка снова активна | Не проверено |
| Восстановить исходный GET_URL и повторить загрузку | Снова отображаются 5 публикаций | Не проверено |
| В DevTools включить Offline и выполнить запрос | Сообщение о сетевой ошибке, кнопка снова активна | Не проверено |
| Отключить Offline и повторить запрос | Запрос снова доступен | Не проверено |

При проверке POST-ошибки введённые данные сохраняются для повторной отправки.
Во время запросов соответствующие кнопки отключены, показаны сообщения загрузки.
Текст публикаций выводится через textContent, HTML из ответа не исполняется.
Повторный GET заменяет список, а не дублирует записи.

## Важно
JSONPlaceholder только имитирует создание публикаций: записи не сохраняются
на сервере постоянно и не появляются в последующем GET. Результат POST
отображается отдельно под формой.

## Перед отправкой
Выполните проверки и внесите реальные результаты в таблицу выше.
Верните правильный GET_URL после проверки 404.
Переименуйте архив в Lab3_ВашаФамилия_ВашаГруппа.zip.
Отдельный отчёт Word/PDF не требуется.
